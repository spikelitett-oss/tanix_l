# Tanix Launcher 1.0 — лаунчер для Android TV

Разработан исключительно для приставок Tanix (Tanix W2 и др.) и слабых процессоров.

## Что внутри
- Главный экран как в Google TV: блок «Продолжить просмотр» (размытый фон из кадра приложения), ряд «Ваши приложения».
- Вкладки: «Для вас», «Приложения», «Магазин приложений» (Google Play).
- «Продолжить просмотр»: в настройках выбираете приложения, которые за него отвечают; последнее открытое — первым.
- Приложение раскрывается из плитки на весь экран, при закрытии сворачивается обратно.
- Фокус: контур + увеличение, только увеличение, только контур или плавный скользящий контур без увеличения;
  толщина и цвет контура настраиваются.
- «Настроить каналы» (как в Android TV Home) и порядок приложений.
- Объёмные значки погоды, язык (русский по умолчанию / English), поля экрана вкл/выкл, «Настройки устройства».
- Имитация Material 3 Expressive, первый запуск с анимацией приветствия в стиле Pixel.
- Пасхалка: 7 нажатий на «Информация о лаунчере» — логотип Tanix, удержание — змейка.

## Сборка (GitHub Actions)
Загрузите все файлы в репозиторий (папка `.github` тоже) — сборка запустится во вкладке Actions.
APK: Artifacts → `TanixLauncher-apk` → `release/TanixLauncher-release.apk`.

## Установка
adb connect IP:5555 → adb install -r TanixLauncher-release.apk  
Главным экраном: `adb shell cmd package set-home-activity com.tanix.launcher/.MainActivity`
